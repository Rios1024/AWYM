KEY ICONS FOR STREAM CONTROLLERS AND MACRO PADS
===============================================
144 x 144 PNG, one per hotkey action (default colors). To make them in your
own show colors or another size, open hotkey-icons.html in your browser.

On a VSD M18 / Stream Dock / Stream Deck: set a key to send the keys shown
here (a "Hotkey" / "Shortcut" action), then drag the matching picture onto
the key. (VSD M18 and Elgato Stream Decks: stream-controller/ has them all
set up already.) The keys are filled in for you in OBS → Settings → Hotkeys by the
setup script (awym-obs-setup.lua, keep it loaded in Tools → Scripts).
