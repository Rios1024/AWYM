Background & badge

The show name appears on the background and the stream screens. Leave it blank to show no name at all. To change only the title on the Main Show background, use the Control Panel's "Background title".

Animation background motion

Applies to the Main Show background. Every scene already has its own motion; these effects layer on top. "Default" goes back to the scene's normal look. Stream screens keep any animation chosen in the Screen Maker.

Glow neon & light effects

Turns the glow up or down everywhere: shot clock digits, neon titles (e.g. Synthwave), glowing court lines, crystal, torch and candle light in the scenes, the camera-frame spotlight and the stats LIVE dot. 0% = no glow, 200% = double. The spotlight never fully disappears, so viewers can still see who has the floor.

Save & reset

Changes show up on every overlay right away, and OBS remembers them. To keep this look in the theme file too (e.g. for another computer), click Copy as theme.css, open theme.css in the overlay folder, replace everything in it, and save. Back to theme.css undoes all changes made here.
