SHOW SCRIPT TEMPLATE (for writers)
==================================
Write the show in Google Docs or Word, then import it in OBS's Content Panel
(Import a script). Every on-screen card lands in the panel's Saved list,
grouped by segment, ready to put on screen with one click (or ▶ Next).

  AWYM-Show-Script-Template.docx   start here. Google Docs: upload it to
                                   Google Drive → right-click → Open with →
                                   Google Docs. Or open it in Word.
  AWYM-Show-Script-Template.md     the same script as Markdown

HOW TO LAY IT OUT (use the doc's built-in heading styles)
  Heading 1     a SEGMENT, e.g. "Hot Takes (5 min)". The "(5 min)" sets the
                shot clock in the Show Runner's rundown. A short line right
                under it (before any Heading 2) is the segment's intro line.
  Heading 2     one ON-SCREEN CARD. The heading is the card's title; the text
                under it is the card: bold, italics, underline, bullet and
                numbered lists and photos all come through.
  Heading 3     big text inside a card.
  A horizontal line (Insert → Horizontal line) starts a new card without a title.
  Note: …       any paragraph starting with "Note:" stays off screen (notes
                for the host or the producer).
  No headings?  The whole doc becomes cards in one segment.

GETTING IT INTO OBS (Content Panel → Import a script)
  Paste:  in the doc press Ctrl+A, Ctrl+C; click the Import box; Ctrl+V.
          Quickest. Photos pasted from Google Docs are links that can stop
          working after a while, so for photos use a file instead.
  File:   Google Docs → File → Download → Microsoft Word (.docx) or
          Markdown (.md), then "Open a file…" (or drop it on the box).
          Web page (.html) and plain text (.txt) work too. PDFs don't.
  Then tick the segments you want, choose whether to fill the Show Runner's
  rundown with them, and click Import. Importing the same script again
  replaces its cards (so writers can keep editing the doc).
