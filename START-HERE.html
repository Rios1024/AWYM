Start Here: OBS Setup

Follow these steps in order. Every box below has the exact address for your computer, so just click Copy and paste it into OBS. Tick each step when it's done; this page remembers your progress.

Your overlay folder

Moved the folder, or setting up OBS on a different computer? Enter its location here.

Paste the folder's location, e.g. C:\Users\You\Documents\awym-obs (Windows: open the folder, click the address bar, copy) or /Users/roger/Documents/awym-obs (Mac: right-click the folder while holding Option → Copy as Pathname).

⚡ The fast way: let OBS build it for you recommended

The kit includes an OBS script, awym-obs-setup.lua, that creates all the scenes and overlays in one click, with the right addresses, sizes and positions. It uses OBS's built-in Scripts feature, so there's nothing extra to install.

  1. Do step 1 below first (folder in a permanent place, OBS installed).
  2. In OBS, open Tools → Scripts.
  3. Click + (bottom left of the Scripts window) and choose awym-obs-setup.lua from this folder:
    Paste this into the file picker's name box to jump straight to it.
  4. On the right, pick the Main Show layout (1–4 people, or 2–5 + a moderator) and what to include.
  5. Click Build my scenes. You'll see "Done!" and the new scenes appear in your Scenes list: Main Show, plus a Show: … scene for every layout (switch between them during the show), the stream screens and Show Overlays (the graphics, shown inside every show scene).
  6. Each person is a color-coded group, Seat 1, Seat 2… (Moderator in the moderator layouts): their camera, avatar, frame and frame effects. Double-click Camera 1 (inside Seat 1) and pick your camera; same for the others.
  7. Still in the Scripts window, copy the five dock addresses it shows and add them as in step 2. (OBS doesn't let scripts add docks.)
  8. Close the Scripts window, but leave the script in the list: it also provides the AWYM hotkeys (step 10).

What's left to do by hand: step 2 (the five docks), picking each camera's device (double-click Camera 1, 2…; they're already cut to a circle for 16:9 cameras), and your own words on the stream screens with the Screen Maker if you want them. Names go in the Control Panel dock. The script skips scenes that already exist, so it won't touch your current setup.

Already built your scenes with an older version? Run the script again with "If Main Show already exists, add the overlays it's missing" ticked. It renames the old "AWYM …" sources to their plain names, adds the new layout scenes, and adds only missing overlays to your Main Show, leaving everything else as it is. For the grouped Main Show, rename yours first (e.g. "Main Show old") and build again.

Get OBS and put this folder somewhere permanentTwo minutes, and it saves headaches later

  2. Make sure this folder is unzipped (not opened inside the zip) and sitting somewhere you won't clean out, like Documents. OBS remembers these exact locations, so if the folder moves later, the overlays go blank. (If that happens, use the box above to get new addresses.)

Add the control docksYour remote controls, docked inside the OBS window

  1. In OBS's top menu, click Docks → Custom Browser Docks…
  2. In the first empty row, type a Dock Name and paste the URL from below. Do the same for the other docks, one per row.

Make your scenes and stream screensCreate the scenes, then build the Starting Soon, Be Right Back, etc. screens with the Screen Maker

3a. Create the empty scenes

A scene is one "page" of your show that you switch between. Make these now; you'll fill them in next.

  1. Find the Scenes panel (bottom left of OBS).
  2. Click + under it, type the scene name exactly as below, and click OK.
  3. Repeat for each scene. Tick them off here as you go:

Use the up/down arrows under the Scenes panel to put them in show order. You switch scenes during the show by clicking them.

3b. How to add a Browser source you'll do this a lot

Every overlay in this kit goes into OBS the same way:

  1. Click the scene in the Scenes panel so it's highlighted.
  2. In the Sources panel next to it, click + → Browser.
  3. Leave Create new selected, type a name you'll recognise (e.g. "Starting Soon screen"), and click OK. A Properties window opens.
  4. Untick "Local file". This matters: the docks can only control overlays added by address.
  5. Paste the address into the URL box.
  6. Type the Width and Height shown with the address (most are 1920 and 1080).
  7. Tick any extra boxes listed with the address, then click OK.
  8. If it doesn't fill the screen, right-click it → Transform → Fit to screen.

To change one later, double-click it in Sources to reopen Properties.

3c. Build each stream screen with the Screen Maker

The Screen Maker is screen-maker.html, in this same folder. You use it to write each screen's words and get its OBS address. Keep this page open too; you'll switch between them.

Open the Screen Maker ↗ (or double-click screen-maker.html in the folder)

Open it on the same computer as OBS, from this folder, so the address it gives you points to the right place.

For each screen scene, do this:

  1. In the Screen Maker, under Screen (top left), click the screen you're making, e.g. Starting Soon.
  2. Under Your words, change the Headline and Message if you like (or keep the defaults). Optional extras:
    • Rotating lines: one per line; they fade in one after another, e.g. "Chat is open, say hi!".
    • Socials: one per line, e.g. "YouTube @yourshow". They show as badges.
    • Bottom line: e.g. "Next show: Friday 8pm".
  3. Under Countdown, pick one (see the table below for each screen):
    • None: no clock.
    • Minutes: counts down that many minutes from the moment the screen appears.
    • Until a time: counts down to a clock time, e.g. 8:00 PM ("we go live at 8").
  4. Under Background, leave Theme default to match the rest of your show, or pick another scene.
  5. Check the preview on the right. It shows exactly what viewers will see.
  6. Click Copy OBS address (under the preview).
  7. Switch to OBS, click the matching scene (e.g. Starting Soon), and add a Browser source as in 3b. Paste the address, size 1920 × 1080. If you chose Minutes, also tick Refresh browser when scene becomes active, so the countdown starts fresh every time you switch to it.
  8. Go back to the Screen Maker and repeat for the next screen.

3d. Main Show comes next

Steps 4–8 fill the Main Show scene, with more detail for each piece. Layer order matters: in the Sources list, things at the top appear in front. When you're done, Main Show's Sources list should read, top to bottom, as below.

Every address is here too, so you can copy them all from one place. They update as you fill in steps 5–7 (names, clock label, cutout shape). Tip: add them bottom first (Background, then Cameras, and so on). Each new source lands at the top of the list, so they end up in the right order without dragging.

If something ends up in the wrong place, drag it up or down in the Sources list.

Cameras: circle cutouts and framesOptional, but it looks great. Do this once per camera or guest feed.

a) Add your camera to Main Show if it isn't there yet (Sources → + → Video Capture Device, or your call/guest source).

b) Fill this in and the numbers update:

c) Crop it square and cut it out. Right-click the camera → Filters. Under Effect Filters, click +:

  1. Add Crop/Pad. Set Left and Right to the crop numbers above (Top and Bottom 0). This makes the camera square.
  2. Add Image Mask/Blend, set Type to Alpha Mask (Alpha Channel), click Browse next to Path, and choose the mask file below. (Or paste the path straight into the box.) Keep this filter below Crop/Pad in the list.

d) Add the themed frame on top of the camera, as a Browser source with this address:

e) Optional: frame effects (🔥 fire, 🧊 ice, ⚡ lightning, 💨 smoke, ✨ sparks, 💥 shake from the Show Runner). Add this Browser source above the frame. The middle stays clear, so it never covers the camera. If the setup script is loaded, it lines this up with its frame for you and keeps it there.

Optional: faces instead of the live camera (pictures listed in avatars/avatars.js; switch them in the Show Runner's Faces section, with hotkeys or a stream deck). Add this Browser source between the camera and the frame, with exactly the frame's position and size. The setup script does it for you and keeps it lined up.

f) Line them up exactly: select a source, press Ctrl+E (Mac: ⌘+E) for Edit Transform, and type in the Position and Size from the table above. Then select them, right-click → Group Selected Items, so they move together.

Test runFive minutes before your first show

  • In the Control Panel dock, the light at the top right should be green ("Overlays connected").
  • Click Start on the shot clock, then Buzzer. You should see it count and hear the buzzer in OBS's audio mixer.
  • Type a name into slot 1 and click Show. The lower third slides in. Click ★ and the camera frame glows.
  • In the Stats Desk, pick a game and click Score.
  • In the Content Panel, type a line, click Show, then Hide.
  • In the Show Runner, the Graphics and Sounds lights should be green. Click Air horn and watch the Sound Effects meter move in OBS's Audio Mixer. Then try 🚨 Clear.
  • Click through each scene and check every screen looks right.
  • Do a short test recording (Controls → Start Recording) and watch it back.

Hotkeys and your stream controllerOptional: run the show from a keyboard, VSD M18, Stream Deck, Loupedeck, Touch Portal or any macro pad

  1. Keep the setup script loaded (Tools → Scripts: awym-obs-setup.lua stays in the list). It adds 73 actions to Settings → Hotkeys, all starting with AWYM:, and fills in the keys below the first time (always Ctrl + Alt + Shift plus one key, so they won't clash with anything). Change any of them there if you like. If you built your scenes before hotkeys existed, click Build my scenes once more: it adds the invisible Hotkeys source that carries them out.
  2. So they work while you're clicked into another window: Settings → Advanced → Hotkeys → Hotkey Focus Behavior → Never disable hotkeys.
  3. Keep the Show Runner dock open: it does the rundown, scoreboard, sound volume and clip actions. (Sounds still play without it, at 80%.)
  4. Set up your controller: open the one you use below. Each has its own steps (a ready-made file to import where there is one). The others stay folded out of the way.
  5. Test: press the key for Air horn and watch the Sound Effects meter move in OBS's Audio Mixer.

If something isn't working

The dock's light stays grey / the buttons don't do anything
  • Open the overlay's properties (double-click the source) and make sure "Local file" is unticked and the URL starts with file:///. Docks can't talk to overlays added with "Local file".
  • Check that the dock and the overlays use the same folder (all addresses on this page match).
  • Restart OBS. If it's still grey, use the overlay directly: right-click it → Interact (the shot clock takes keyboard shortcuts; see the README).
An overlay is blank or shows an error
  • The folder probably moved or was renamed. Enter its new location in the box at the top, then paste the new addresses into each source.
  • Make sure the folder is unzipped, not opened from inside the zip.
The text looks plain, not the fancy fonts

The fonts load from Google Fonts, so the computer needs internet the first time. Right-click the source → Refresh once you're online.

No buzzer sound

Open the shot clock's properties and tick Control audio via OBS. It then shows in the Audio Mixer, so make sure it isn't muted there and that your stream or recording includes it.

I changed colors, fonts or the theme, and nothing changed

If you used the Theme Panel dock, changes show instantly with no refresh needed. If you edited theme.css or used the Theme Editor, right-click each source → Refresh, and restart OBS for the docks. Note that the Theme Panel's live look sits on top of theme.css; click Back to theme.css in it to see the file's look again.

The countdown doesn't restart when I switch to a screen

Open that source's properties and tick Refresh browser when scene becomes active. Or start a fresh countdown from the Control Panel's Stream screens section.

The Stats Desk can't reach ESPN

Check the internet connection. The stats come from ESPN's free public feed, which is unofficial and can change. If search can't find a player, paste their espn.com player link instead.

OBS feels slow or my computer runs hot
  • Animated backgrounds use some graphics power. In the Background Picker, choose Low intensity or a calmer scene.
  • In a busy source's properties, tick Use custom frame rate and set 30.
  • Tick Shutdown source when not visible on screens in scenes you're not using.
